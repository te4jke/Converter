# Converter

Небольшой конвертер файлов между популярными форматами. Работает двумя способами: как веб-страница (загрузил файл, выбрал во что превратить, скачал результат) и как консольная утилита.

Учебный проект, делали на практике. Рассчитан на Windows 10/11 и Python 3.13.

## Что умеет

**Конвертация.** Если прямого преобразования нет, программа сама строит цепочку через промежуточные форматы. Например, DOCX → PDF пойдёт как DOCX → TXT → PDF.

| Группа | Форматы |
|---|---|
| Документы | TXT, DOCX, HTML, PDF |
| Таблицы | CSV, XLSX, JSON |
| Картинки | PNG, JPG, WEBP, BMP, GIF |

Что важно знать:

- Цепочки через TXT, CSV и JSON теряют оформление (шрифты, картинки, стили). В веб-интерфейсе такие преобразования помечаются.
- Картинка → PDF остаётся картинкой, текста внутри нет. Дальше по цепочке такой PDF не идёт.
- Картинка → TXT работает через распознавание текста (OCR) и появляется, только если в системе установлен Tesseract (см. ниже).
- Формат файла определяется по содержимому, а не по расширению. Если вы загрузили PNG с названием `photo.jpg`, программа это заметит и сообщит.

**Дополнительные операции** (только в веб-версии):

- склеить несколько файлов в один PDF;
- разрезать PDF на страницы (результат приходит архивом);
- сжать картинку (JPG, PNG, WEBP) с выбором качества и максимальной стороны.

Полный список преобразований всегда можно получить командой `python main.py --list`.

## Установка

Нужны Python 3 (с [python.org](https://www.python.org/downloads/windows/), при установке отметьте галочку «Add python.exe to PATH») и Git. Дальше всё делается в PowerShell.

```powershell
git clone <адрес репозитория>
cd Converter

python -m venv .venv
.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

Если PowerShell ругается, что выполнение скриптов отключено, разрешите их для текущего пользователя и повторите активацию:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

В обычной командной строке (`cmd`) окружение активируется командой `.venv\Scripts\activate.bat`.

### Распознавание текста (по желанию)

Без этого всё остальное работает, просто не будет преобразований «картинка → TXT».

1. Скачайте установщик Tesseract для Windows (например, сборку UB Mannheim: https://github.com/UB-Mannheim/tesseract/wiki).
2. При установке в списке языков (Additional language data) отметьте **Russian**.
3. Добавьте папку установки (обычно `C:\Program Files\Tesseract-OCR`) в переменную окружения `Path`.
4. Откройте новое окно PowerShell и проверьте, что команда `tesseract --version` отвечает.

Программа ищет `tesseract` именно через `Path`, так что без шага 3 распознавание не включится.

Используются русский и английский языки. Если русский не установлен, распознаётся только английский.

## Запуск

### Веб-интерфейс

```powershell
python app.py
```

После этого откройте в браузере http://127.0.0.1:5000. Остановить сервер можно через `Ctrl+C`.

Сервер слушает только `127.0.0.1`, то есть доступен только с вашего компьютера. Это встроенный сервер Flask для разработки. Выставлять его в интернет в таком виде не стоит.

### Командная строка

```powershell
python main.py <исходный файл> <результат>

python main.py report.docx report.pdf
python main.py table.csv table.xlsx
python main.py -l                    # список всех преобразований
```

Формат берётся из расширений файлов. Код возврата `0` при успехе и `1` при ошибке (в PowerShell его видно в `$LASTEXITCODE`), так что утилиту можно вызывать из скриптов.

## Ограничения

Заданы константами в начале `app.py`:

| Параметр | Значение |
|---|---|
| Размер одного файла | до 25 МБ |
| Файлов за один раз | до 30 |
| Общий размер загрузки | до 150 МБ |
| Параллельных конвертаций в пакете | 4 |

Если нужно больше, поменяйте `MAX_SIZE`, `MAX_FILES`, `MAX_TOTAL` или `WORKERS` и перезапустите сервер.

## HTTP API

Фронтенд общается с сервером через обычные запросы, ими можно пользоваться и напрямую.

| Метод и адрес | Что принимает | Что отдаёт |
|---|---|---|
| `GET /api/formats` | ничего | поддерживаемые форматы, цепочки, лимиты, доступен ли OCR |
| `POST /api/convert` | `file`, `target` | готовый файл |
| `POST /api/batch` | `files` (несколько), `target` | ZIP с результатами и файлом `ОШИБКИ.txt`, если что-то не получилось |
| `POST /api/merge` | `files` (от двух) | один PDF |
| `POST /api/split` | `file` (PDF) | ZIP со страницами |
| `POST /api/compress` | `file`, `quality`, `max_side` | сжатая картинка |

Пример:

```powershell
curl.exe -F file=@report.docx -F target=pdf http://127.0.0.1:5000/api/convert -o report.pdf
```

Пишите именно `curl.exe`: просто `curl` в PowerShell является псевдонимом другой команды и с этими параметрами не заработает.

Дополнительные сведения приходят в заголовках ответа: `X-Route` (по какой цепочке шла конвертация), `X-Detected` (какой формат определился на самом деле), `X-Note`, `X-Done` и `X-Failed` для пакета, `X-Pages`, `X-Before` и `X-After` для разбиения и сжатия.

Ошибки приходят в виде JSON: `{"error": "текст"}` и код 400 (или 500 для непредвиденного). Пути к временным файлам в сообщения не попадают.

## Тесты

```powershell
python -m unittest discover -s . -t .
```

Тесты используют только стандартный `unittest`, дополнительно ничего ставить не нужно. Для OCR отдельных тестов нет, потому что он зависит от системного Tesseract.

## Устройство проекта

```
app.py           веб-сервер (Flask) и все HTTP-ручки
main.py          консольная утилита
core/
  manager.py     таблица конвертеров и поиск цепочки между форматами
  formats.py     расширения файлов и их форматы
  sniff.py       определение формата по содержимому
  operations.py  склейка и разрезание PDF, сжатие картинок
  exceptions.py  свои исключения
converters/      сами конвертеры, по файлу на группу форматов
  fonts/         шрифт DejaVu Sans, нужен для PDF с кириллицей
static/          страница, скрипт и стили веб-интерфейса
tests/           тесты
```

Как это работает в общих чертах: в `core/manager.py` лежит словарь `CONVERTERS`, где каждой паре «из формата → в формат» сопоставлена функция. Когда нужного прямого преобразования нет, ищется кратчайшая цепочка по этому словарю. Шаги, на которых теряется структура документа, считаются «дороже», поэтому выбирается маршрут с меньшими потерями.

### Как добавить новый формат

1. Напишите функцию `имя(src, dst)` в подходящем файле из `converters/`. При проблемах она должна бросать `ConversionFailedError`.
2. Добавьте пару форматов и функцию в `CONVERTERS` в `core/manager.py`.
3. Если формат новый, впишите расширение в `core/formats.py` и, если нужно, правило определения в `core/sniff.py`.
4. Допишите тест в `tests/`.

Веб-интерфейс подхватит новое преобразование сам, он берёт список из `/api/formats`.

## Если что-то не работает

- **`python` не найден**: Python не добавлен в `Path`. Переустановите его с галочкой «Add python.exe to PATH» или запускайте через `py` вместо `python`.
- **`ModuleNotFoundError`**: не активировано виртуальное окружение или не выполнен `pip install -r requirements.txt`.
- **Нет преобразования картинка → TXT**: не установлен Tesseract. Проверьте `tesseract --version` в новом окне PowerShell и наличие папки Tesseract в `Path`.
- **Порт 5000 занят** (сообщение `Address already in use` или `Only one usage of each socket address`): закройте предыдущий запуск или поменяйте `port=5000` в конце `app.py`. Найти, кто занимает порт, можно командой `netstat -ano | findstr :5000`.
- **«Слишком большой объём загрузки»**: сработал лимит, см. раздел «Ограничения».
- **Кракозябры в CSV, открытом в Excel**: CSV из XLSX сохраняется в UTF-8 с BOM, и Excel его читает нормально. Остальные CSV идут в UTF-8 без BOM, их лучше открывать через импорт с ручным выбором кодировки UTF-8.
